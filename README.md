# Just don't be weird, OK?

**A cute dating card game with increasingly questionable options for the [Global Game Jam 2024](https://globalgamejam.org/games/2024).**

**Play it on [itch.io](https://thomas3913.itch.io/just-dont-be-weird-ok).**

## About

Game is the result of the game jam of a team of 4 using Unity 

**Theme:** theme  
**Jam Duration:** 48h  
**Team:** ruebenritter & [thomas](link) (code), [callion](link) & [hangman]() (writers), [myusome]() (art), dilara/nefera (sound design)
**Tools:** Unity C# | Git + Git LFS |

## Lessons Learned

- Zweiter Coder = herausforderung aufgaben sinnvoll aufzuteilen, um parallel am projekt zu arbeiten und unterschiedlichen wissenstand zu mangagen/balancieren
- herausforderung gruppen management und die vielen ideen in konkrete lösungen und ein stimmiges spiel zu formen nach beispiel tür-design 
- Ziel der Teilnahme an game jams war zu lernen kleine projekte zu planen (scope) und umzusetzen (finish/publish); dieses spiel war der dritte jam und erste erfolg
